SupplySafeAI — C# / ASP.NET Core
Plataforma de resiliencia: detectar, predecir, analizar impacto y actuar. Monitorea envíos, inventario y riesgos; incluye análisis de riesgo y consulta de TRM USD/COP.

cargoops — NestJS · PostgreSQL · Redis
Logintec CargoOps: monolito modular orientado a eventos. Tracking de embarques, integración con navieras (Maersk, Hapag-Lloyd, MSC), conciliación con Bitrix24 y actualización de ETD/ETA y TRM.

RecyIA — JavaScript · Ollama
ForgeAI: analizador de rutinas de fitness con modelos locales. Puntúa la rutina, sugiere progresión de pesos y genera un plan. Los datos no salen de la máquina.
